# 복학

출처: https://www.wku.ac.kr/campus-life/academic/student-records/return.html
담당부서: 학사지원과 063-850-5228 (문의는 소속 단과대학 교학과, 공과대학 850-6703)

## 관련규정
학칙 제44조(복학)

### 1. 정의
휴학을 하고 있던 학생이 다시 학교에 복귀하는 것

### 2. 대상
해당 학기 복학을 원하는 자

### 3. 신청시기
직전학기 종강일 이후 ~ 개강 후 4주 이내

### 4. 신청절차
1) 웹정보서비스 – 정보서비스 – 학적관리 – 복학신청 접속
2) 복학학과 선택(필수서류 있는 경우 서류 업로드)
3) 복학신청 완료

### 5. 복학유형
| 구분 | 내용 | 증빙서류 |
|---|---|---|
| 일반복학 | 가사휴학, 질병/임신/출산/육아휴학, 창업휴학, 직권휴학을 했던 자가 정해진 기일 내 복학 | 없음 |
| 군복학 | 군복무를 필하고 정해진 기일 내 복학 | 전역증 또는 전역증명서 |
| 유급복학 | 유급휴학을 했던 자가 정해진 기일 내 복학 | 없음 |

### 6. 유의사항
- 휴학기간 만료 시 소정의 등록기간까지 복학해야 함. 단, 휴학기간 만료 전이라도 휴학사유 종결 시 복학 가능
- 군복학자는 개강 후 4주 이내 복학해야 하나, 전역 이전이라도 수업일수에 지장 없는 자는 증빙서류(전역예정증명서, 휴가증사본, 부대장추천서) 첨부로 복학 가능
- 군복학자는 학교 홈페이지에서 예비군 신고 필요(예비군연대: 063-850-5492)
- 복학 일정 고의 지연 시 출석일수 부족으로 저조한 성적을 받을 수 있음
- 복학하지 않으면 휴학기간 경과로 제적처리 됨 — 부득이한 사유 시 반드시 연장휴학 신청 필요
