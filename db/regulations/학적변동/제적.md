# 제적 (자퇴 포함)

출처: 원광대학교 학칙 제45조(자퇴 및 제적), 학칙시행규칙 제102조(2026.6.26. 개정 현행), 학교 홈페이지 제적 안내 https://www.wku.ac.kr/campus-life/academic/student-records/expel.html
담당부서: 학사지원과 063-850-5228 (문의는 소속 단과대학 교학과 / 등록금 환불은 재무과 063-850-5336)

※ 제적 사유는 현행 학칙·학칙시행규칙을 기준으로 적었다. 2026.6.26. 개정으로 의과·치과·한의과대학만 해당하던 제적 사유 일부의 대상이 바뀌었다. 학교 홈페이지 안내와 다른 부분은 맨 아래 "홈페이지 안내와 다른 점"에 따로 적었다.

## 관련규정
학칙 제45조(자퇴 및 제적), 제26조(재학연한), 제43조(휴학), 제75조(학사학위취득유예), 학칙시행규칙 제68조(학사경고), 제99조(유급 및 제적의 특례), 제101조(유급휴학), 제102조(의과대학, 치과대학, 한의과대학, 약학대학, 간호대학의 제적)

### 1. 정의
제적 사유에 해당하거나 본인이 자퇴를 신청해 승인된 경우 학업을 그만두게 하는 것

### 2. 대상
제적 사유에 해당하거나 스스로 학업을 그만두려는 자

### 3. 자퇴
- 자퇴하려면 자퇴를 신청하고 지도교수 상담(보호자 상담 포함)을 거쳐 총장의 승인을 받아야 한다(학칙 제45조 제1항).
- 신청 절차(홈페이지 안내)
  1) 웹정보서비스 – 정보서비스 – 학적관리 – 자퇴신청 접속
  2) 자퇴신청서 내용 기재 및 제적상담기록부 작성
  3) 본인 및 보호자 지도교수 상담 진행
  4) 자퇴신청 완료

### 4. 모든 학생의 제적 사유 (학칙 제45조 제2항)
다음 중 하나에 해당하면 소속 대학장의 제청으로 총장이 제적한다.
| 사유 | 내용 |
|---|---|
| 휴학기간 경과 | 휴학기간이 끝난 뒤 4주 이내에 복학하지 않은 경우 |
| 미등록 | 정해진 등록기간 안에 등록을 마치지 않은 경우 |
| 휴학연한 초과 | 휴학연한을 넘긴 경우(휴학연한은 "휴학" 문서 참고) |
| 재학연한 초과 | 재학연한을 넘긴 경우. 다만 학사과정은 재학연한에 제한이 없어(학칙 제26조 제1항) 학·석사연계과정이 아니면 해당하지 않는다 |
| 징계 | 학생지도위원회에서 징계에 의한 제적으로 결정된 경우 |
| 사망 | 사망한 경우 |
| 미수강 | 사유 없이 한 과목도 수강신청하지 않은 경우. 다만 학사학위취득유예생은 제외한다 |
| 학사경고 누적 | 학사경고(학기 평균평점 1.75 미만, 시행규칙 제68조)를 연속 4회 또는 통산 6회 이상 받은 경우 |
| 자퇴 | 자퇴 신청 절차를 거쳐 최종 승인된 경우 |

- 의과대학, 치과대학, 한의과대학, 약학대학, 간호대학 학생은 학사경고 대신 유급을 하므로(시행규칙 제100조 제1항, 작업치료학과·응급구조학과 제외) 학사경고 누적 제적 대신 아래 5항의 유급 제적을 적용한다.

### 5. 의과대학·치과대학·한의과대학·약학대학·간호대학 학생의 제적 (시행규칙 제102조)
다음 중 하나에 해당하면 제적한다(학칙 제45조 제2항 단서, 시행규칙 제99조).
| 사유 | 내용 | 대상 |
|---|---|---|
| 학칙 제45조 | 위 4항의 사유에 해당하는 경우 | 다섯 단과대학 모두 |
| 유급휴학 미이행 | 유급한 학생이 다음 학기에 유급휴학을 하지 않은 경우(시행규칙 제101조) | 다섯 단과대학 모두 |
| 유급 누적 | 연속하여 4회 또는 통산 6회 유급한 경우 | 다섯 단과대학 모두 |
| 교과목 미수강 | 교육과정에서 정한 해당 학년·해당 학기의 교과목을 전혀 수강신청하지 않은 경우 | 의과·치과·한의과대학(약학대학·간호대학 제외) |
| 신입학 첫 학기 출석 미달 | 신입학 첫 학기에 수강 교과목 중 4분의 1 이상이 출석미달이고 학장이 제적을 제청한 경우 | 의과·치과·한의과대학(약학대학·간호대학 제외) |

- 재입학한 학생은 제적 전의 학사경고, 유급, 휴학 횟수를 재입학 이후와 합산하지 않는다(학칙 제46조 제3항).

### 6. 유의사항 (홈페이지 안내)
- 재학 중 자퇴 신청 시 등록금 반환은 자퇴 신청일 기준, 휴학 중 자퇴 신청 시에는 휴학 신청일 기준 — 환불 관련은 재무과(063-850-5336) 문의
- 당해학기 수업시간의 2/3 이상(조기시험신청 자격일) 경과 후 자퇴 시 성적기재 여부 선택 필요 (단, 성적사정일 이후 자퇴는 무조건 성적 표기됨)

### 홈페이지 안내와 다른 점
- 홈페이지는 "신입학 첫 학기 출석 미달 + 학장 제청" 제적을 약학대학·간호대학을 포함한 다섯 단과대학 대상으로 적는다. 현행 시행규칙(2026.6.26. 개정)은 약학대학·간호대학을 제외한다.
- 홈페이지 제적 유형표에는 휴학연한 초과, 재학연한 초과, 징계, 사망이 없고, 미수강 제적의 학사학위취득유예생 예외도 없다. 학칙 제45조 제2항에는 있어 함께 적었다.
