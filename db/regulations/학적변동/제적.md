# 제적 (자퇴 포함)

출처: https://www.wku.ac.kr/campus-life/academic/student-records/expel.html
담당부서: 학사지원과 063-850-5228 (문의는 소속 단과대학 교학과, 공과대학 850-6703 / 등록금 환불은 재무과 063-850-5336)

## 관련규정
학칙 제45조(자퇴 및 제적), 학칙시행규칙 제102조(의과대학, 치과대학, 한의과대학, 약학대학, 간호대학의 제적)

### 1. 정의
제적요건에 해당하는 사유가 발생한 경우 학업을 중단하도록 조치하는 것

### 2. 대상
제적요건에 해당하거나 스스로 학업을 중단하고자 하는 자

### 3. 자퇴 신청절차
1) 웹정보서비스 – 정보서비스 – 학적관리 – 자퇴신청 접속
2) 자퇴신청서 내용 기재 및 제적상담기록부 작성
3) 본인 및 보호자 지도교수 상담 진행
4) 자퇴신청 완료

### 4. 제적유형
| 구분 | 내용 | 대상 |
|---|---|---|
| 휴학기간경과 제적 | 휴학기간 경과 후 4주 이내 복학하지 않은 자 | 모든 단과대학 |
| 미등록 제적 | 매 학기 정해진 등록기간에 등록하지 않은 자 | 모든 단과대학 |
| 미수강 제적 | 사유 없이 전 과목 수강신청 하지 아니한 자 | 모든 단과대학 |
| 학사경고 제적 | 학사경고(1.75미만) 연속 4회, 통산 6회 이상인 자 | 한의과/치과/의과/약학/간호대학 제외 (컴퓨터소프트웨어공학과 등 일반학과 해당) |
| 자퇴 | 자퇴 신청 절차를 밟고 최종 승인된 자 | 모든 단과대학 |
| 유급 제적 | 유급 연속 4회, 통산 6회 이상인 자, 유급대상자이나 유급휴학 아니한 자 | 한의과/치과/의과/약학/간호대학만 해당 |
| 교과목 미수강 (의학계열) | 교육과정으로 정한 해당 학년의 해당 학기에 개설된 교과목을 수강신청 아니한 자 | 한의과/치과/의과대학만 해당 |
| 학장의 제적 제청 | 신입학 첫 학기에 수강과목 기준 1/4 이상 출석 미달인 자로 학장의 제적 제청이 있는 자 | 한의과/치과/의과/약학/간호대학만 해당 |

### 5. 유의사항
- 재학 중 자퇴 신청 시 등록금 반환은 자퇴 신청일 기준, 휴학 중 자퇴 신청 시에는 휴학 신청일 기준 — 환불 관련은 재무과(063-850-5336) 문의
- 당해학기 수업시간의 2/3이상(조기시험신청 자격일) 경과 후 자퇴 시 성적기재 여부 선택 필요 (단, 성적사정일 이후 자퇴는 무조건 성적 표기됨)
