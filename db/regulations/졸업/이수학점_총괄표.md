## 1. 학과(부) 개편 현황 — 정정본
공과대학 산하 "공학3계열"로 아래 두 전공이 광역단위 모집으로 통합됨:
- 컴퓨터·소프트웨어공학전공
- 게임콘텐츠학과전공

**⚠️ 정정 (최초 기록 오류 수정)**: 개편 시점은 **2025학번이 아니라 2026학번부터**임.
- **~2025학번**: "컴퓨터·소프트웨어공학과"라는 독립 학과로 모집/운영 (창의공과대학 소속). 전공이수기준 계 **75학점**(기본전공 19학점 이상 + 선택전공), 졸업학점 **136점** 체계.
- **2026학번~**: "공학3계열"로 광역 모집. 2학년 진급 시 컴퓨터·소프트웨어공학전공 또는 게임콘텐츠학과전공 중 하나를 선택. 전공 이수유형(①~③) 선택제, 전공계 **72학점**, 졸업학점 **130점** 체계.

## 2. 코호트(입학년도)별 "주전공 이수학점" 기준 — 창의공과대학/컴퓨터·소프트웨어공학과 계열만 발췌

이 절이 이전에 없던 핵심 데이터임. 대학 전체 학과가 아니라 **컴퓨터·소프트웨어공학과(구) / 공학3계열(신) 관련 행만** 정리.

### 2026학년도 입학생 (공학3계열)
"주전공 이수학점은 기본전공 이수학점, 필수전공 과목을 포함하여 아래와 같이 이수" — 단, **광역단위 계열전공 학생은 이수유형 ①~③ 중 하나를 선택**하여 전공 교육과정을 이수:

| 이수유형 | 구성 | 공학계열 전공 총계 |
|---|---|---|
| ① 복수학위형 | 제1전공 36학점 + 제2전공 36학점 (각 기초12+심화15+응용9) | 72 |
| ② 전공심화형 | 주전공 기초(12)+심화(15)+응용(9)을 포함하여 계열별 이수학점 (인문·사회·예체능 66 / 사범대·자연계열 69 / **공학계열 72**) | 72 |
| ③ 전공융합형 | 주전공 48학점 + 타전공 MD 2개(각 12학점) = 72, 기초(12)+심화(15)+응용(9) 포함 48학점 | 72 |

※ 세 유형 모두 공학계열 기준으로는 결과적으로 **72학점**으로 수렴함.

복수전공 이수자의 계열별 최소전공 인정학점: 인문사회계열 36 / 군사학과 42 / 사회복지학과 51 / **자연계열·공학계열·예체능계열 48** / 건축학과(5년제) 66 / 전문학사 학위과정 38.

### 2025학년도 입학생 (아직 개별학과 체계 — 컴퓨터·소프트웨어공학과 해당)
창의공과대학 행: "건축학과(5년제), 인공지능융합학과를 제외한 모든 학과" → **기본전공 19학점 이상 이수 + 선택전공 이수, 계 75학점**

(※ 2025학번의 "광역단위 계열전공" 카테고리는 창의문화융합계열/농생명바이오계열/디자인융합계열에만 적용되고 공학계열은 미포함 — 즉 컴퓨터·소프트웨어공학과는 2025학번까지는 개별학과 그대로 유지)

### 2023~2024학년도 입학생
창의공과대학 행: "건축학과(5년제), 인공지능융합학과를 제외한 모든 학과" → **기본전공 19학점 이상 이수 + 선택전공 이수, 계 75학점** (2025학번과 동일)

### 2017~2022학년도 입학생
창의공과대학 행: "건축학과(5년제), 인공지능융합학과를 제외한 모든 학과" → **기본전공 19학점 이상 이수 + 선택전공 이수, 계 75학점** (동일)

### 2010~2016학년도 입학생
"자연과학대, 생활과학대, 공과대, 생명자원과학과" 그룹 → **기본전공 19학점 이상 + 선택전공 이수 + 응용전공 이수, 계 72학점**

※ 모든 코호트 공통 각주: 매학기 개설되는 자기계발심층상담 반드시 이수(2020학번 8회 이상, 2019학번까지 6회 이상, 편입생 3회 이상, 전과생은 당초 입학 학번에 따름)

### 요약: 전공 총계 학점 변화
| 코호트 | 전공 총계 | 비고 |
|---|---|---|
| 2010~2016학번 | 72학점 | 기본전공19+선택전공+응용전공 |
| 2017~2025학번 | **75학점** | 기본전공19+선택전공 — 가장 오래 유지된 안정적 기준 |
| 2026학번~ | 72학점 | 공학3계열, 이수유형 선택제 |

**⚠️ 이전 기록 정정**: 이전에 "전공 72학점"을 2025학번까지 포함한 전체 컴퓨터·소프트웨어공학과에 적용 가능한 것처럼 서술한 부분(편입생 관련 답변 등)은 틀림. **2017~2025학번은 75학점**이 맞고, 72학점은 2010~2016학번(구식)과 2026학번(신식, 공학3계열)에만 해당하며 산출 근거도 서로 다름.

## 3. 이수학점 기준총괄표 — 공학3계열 행 (교양 구조, 2026학년도 교육과정 총괄표 기준)
| 구분 | 값 |
|---|---|
| 교양필수 (건학이념/대학생활/전공탐색과진로) | 3+2+4 = 9 |
| 교양기초 소양교육(생명존중교육/도덕·문화·평화) | 4+3 |
| 교양기초 기초교육(시와표현/글로벌의사소통/과학과기술) | 3+3+3 |
| 교양선택 리버럴아츠교육 | 4개 영역 중 3개 영역 이상에서 12학점 |
| 교양학점 계 | 37 |
| 전공 (이수유형별) | 72 (위 2절 참고) |
| 자유선택 | 21 |
| 졸업논문(시험) | P/F |
| 졸업학점 총계 | **130** |

검증: 37(교양) + 72(전공) + 21(자유선택) = 130 ✓ (2026학번 공학3계열 기준)

## 6. 이 앱 설계에 주는 시사점
- 온보딩에서 이미 "입학년도"를 입력받고 있으므로, **학번 구간별 분기**가 필요함: 2010~2016 / 2017~2025 / 2026~ 세 구간으로 전공 총계 학점이 다름(72/75/72, 산출 근거도 다름)
- **2026학번~만 "세부전공(트랙)" 필드 필요** — 2학년 진급 시 컴퓨터·소프트웨어공학전공 vs 게임콘텐츠학과전공 선택. 2025학번 이하는 트랙 개념 없이 단일 학과.
- **최소전공 인정학점(자연·공학·예체능계열 48학점)은 복수전공 이수자·편입생·3학년 전과생 공통 적용** — 14쪽 각주로 확정됨. 이 세 부류는 일반 재학생의 전공 총계(72~75학점)를 다 채우는 대신 완화된 48학점만 채우면 됨. ([[복수전공]], [[전과]], [[편입생_교육과정]] 문서 모두 갱신됨)
- 일반 재학생(전과/편입/복수전공 아닌 경우)의 전공이수학점은 코호트에 따라 75학점(2017~2025학번) 또는 72학점(2026학번~ 이수유형별) 적용
