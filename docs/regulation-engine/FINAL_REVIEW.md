## 1. 한눈에 보기

### 1-1. 비유 — "학생 개인용 규정 내비게이션"

종이 지도책(학번별 교육과정 책자, 학칙)을 그냥 펼쳐 주는 게 아니라, **"나는 2022학번 컴소공 일반 입학생이고 오늘 기준"**이라는 현재 위치를 넣으면 **지금 나에게 해당되는 길(규정)**을 찾아 주는 내비게이션이다.

| 내비게이션 | 이 시스템 |
|---|---|
| 지도 데이터 | 교육과정 책자(학번별 졸업요건·과목표), 학칙·학칙시행규칙 원문 |
| 도로 공사 안내 | 개정 이력(학칙 부칙·개정 표시), 교육과정 변경 이력 |
| 경로 계산 규칙 | 경과조치 조문(시행규칙 제5조·제13조·제14조 등)을 코드로 옮긴 판단 함수 |
| "이 구간은 지도가 오래됨" 경고 | **신뢰도**(확정 / 추정 / 자료 불충분 / 자료없음) |

이 비유에는 한계가 있다. 지도 데이터 일부가 서로 다른 말을 한다(§6 F-1). 지도가 아예 없는 구간도 있다(2026년 이전 학칙 판본).
