## 7. 재현 방법 (`scripts/audit/`)

PDF는 레포 밖 짧은 경로에 풀어 둔다(예: `C:\tmp\curriculum-pdf\YYYY.pdf`). Windows·Node 24 기준. 의존성은 `pdfjs-dist`(server의 `pdf-parse`가 끌고 옴).

```bash
node scripts/audit/extractPdfCourseRows.mjs C:/tmp/curriculum-pdf/2023.pdf --out C:/tmp/rows2023.json
node scripts/audit/diffPdfVsJson.js C:/tmp/rows2023.json 2023 --issue <이슈260.txt> --exclude-pages 278-279 --md docs/regulation-engine/audit/courses-2023.md

# 졸업요건: 총괄표 대조(텍스트 PDF) — 쪽은 --pages로 지정, 스캔본은 이미지로 읽은 값을 JSON으로 만들어 같은 스크립트에 넣는다
node scripts/audit/extractSummaryTable.mjs C:/tmp/curriculum-pdf/2023.pdf --pages 28-30 --out C:/tmp/sum2023.json
node scripts/audit/auditRequirements.js 2023 C:/tmp/sum2023.json
node scripts/audit/parseSummaryMd.js db/regulations/교육과정/2017_교육과정_해설.md --out C:/tmp/sum2017.json   # 전사본(md) → 같은 형식

# 학년도 간 일관성(A,B,A), 학점 이상치, RAG 문서 연도, 로컬 DB↔JSON 일치
node scripts/audit/crossYearConsistency.js --out C:/tmp/xyear.json
node scripts/audit/creditAnomalies.js
node scripts/audit/auditRagDocs.js
node scripts/audit/dbVsJson.js        # 로컬 DB(.env)만 읽는다
```
