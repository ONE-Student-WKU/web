# 규정 사실 감사 (Part 1, 2026-10-05 시점)

엔진이 의존하는 규정 사실 하나하나에 대해 **무엇이 원문으로 확인됐고, 무엇이 추정인지**를 정리한다. 신뢰도 열은 엔진이 해당 규칙에 내는 값이다.
원문 위치는 레포 기준: 학칙·시행규칙·수업관리규정 = `db/regulations/_source/*.txt`, 책자 = `db/regulations/교육과정/*.md`, 내부 정리 = `db/regulations/{졸업,전공선택,…}/*.md`.

### A 정정·보강 (파트 2, 2026-10-05) — 위 표는 그대로 두고 여기에 덧붙인다

- **A-1 정정**: "학번별 경과조치 문서가 레포에 없어 학번별 값은 책자로만 확인"은 절반만 맞다. 보유한 현행 학칙의 **[별표 4]에 학번별 졸업학점 표가 이미 있다** — ① 2026학년도 입학생 이후, ② 2025학년도 입학생, ③ 2013~2024학년도 입학생(`<개정 2026. 4. 10., 2026. 6. 26.>`), ④ ~2012학년도 입학생. 학칙 제69조·제71조(졸업학점은 [별표 4]와 같이 정함)와 시행규칙 제118조① 제2호("이수학점: 「원광대학교 학칙」 [별표 4]에 따르며")가 위임한다. 즉 **졸업 총학점이 학번(입학 학년도)별로 갈린다는 것 자체는 보유 원문으로 확정**된다. 다만 [별표 4]는 대학·계열 단위 총학점(120/130/136/140/160…)이고 학과별 교양·전공 분할은 여전히 책자 값이며, 종전 2025-08-29자 부칙의 다른 경과조치는 여전히 미보유.
- **A-2 보강**: 긴장은 대상이 다르다고 보면 풀린다 — 졸업 **총학점**은 [별표 4]가 학번별로 고정(COHORT_ONLY), **교육과정(과목 편성·이수구분)**은 제13조①에 따라 개편 시 전 학년 적용(ALL_ENROLLED)하되 ②~④ 경과조치(TRANSITIONAL). 파트 2 판단 함수(`resolveApplicableRules`)가 이 구분으로 계산한다(DECISIONS D-25).
- **A-8 보강**: 학칙 부칙(2026.04.10.) 제2조②("[별표 4]의 개정사항은 2026년 8월 졸업자부터")의 대상은, 개정 표시가 붙은 [별표 4] ③(2013~2024학년도 입학생 표)뿐이다. 2026년 8월 이전 졸업자에게 적용되는 개정 전 표의 값은 여전히 미보유.
