# wku-ai-chat

Wonkwang University Intranet Mock AI Chat Service.

This project is a monorepo containing:
- `/client`: Frontend interface built using Vite + React.
- `/server`: Node.js + Express backend serving mock intranet databases and AI chatbot API.
- `/db`: Database schema, mock data seeds, and ERD.

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Setup environment variables**:
   Copy `.env.example` to `.env` and fill in the values.

3. **Start development server**:
   ```bash
   npm run dev
   ```
