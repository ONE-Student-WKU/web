# 비교과 프로그램·행사 공지 출처

학생의 학과·학년·진로에 맞는 비교과 프로그램·행사를 골라 보여 주는 기능(아직 구현 전)을 위해, 공지가 어디에 올라오고 무엇을 가져올 수 있는지 조사한 기록. **2026-10-13 확인.** 여기서 "비교과"는 수업 밖에서 참여할 수 있는 모든 프로그램·행사(특강, 캠프, 상담, 공모전, 봉사, 취업 프로그램 등)를 넓게 뜻한다.

## 결론
- 공지가 가장 많이 모이는 곳은 웹정보서비스 **봉황 BBS "공지사항(학생)"**(하루 10건 이상, 여러 부서)이지만 **로그인 전용 + robots.txt 전체 거부**라 가져오지 않는다. 같은 공지를 받는 **원광대학교 알리미 앱**도 웹정보서비스 계정 로그인이 필요하다. 로그인 없이 같은 공지를 보여 주는 대체 사이트는 찾지 못했다(모바일 주소, 공식 SNS, 웹 검색 확인).
- **학과 홈페이지와 센터 사이트 대부분이 워드프레스로 RSS를 공개**하고 robots.txt 제한이 없다 → 이 목록부터 모을 수 있다. 하루 1~2회 새 글만 읽는다(피드는 최근 10건).
- 로그인 전용 공지는 학교 허락을 받은 뒤에만 다룬다 — 후속 문의 이슈 #342(#332 C-5 후속).

## 공지 제목에서 쓸 수 있는 단서
봉황 BBS 화면(사용자 제공 스크린샷)에서 확인한 형식 — 다른 출처도 비슷하게 쓴다.
- 작성 부서(대학일자리플러스센터, 상담과, 교수학습개발센터 …) → 분야 추정
- W포인트 표시: `(WP10)`, `(WP 20)`, `(W포인트 지급)` → WK역량인증제 비교과 W-point와 연결
- 대상·일정: "계열별", "선착순 5명", "10.28(수)~29(목)"
