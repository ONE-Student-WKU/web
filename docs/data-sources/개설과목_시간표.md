# 개설과목(학과별 시간표) 데이터

앱의 `course_offerings`(과목 관리의 과목 검색, 챗봇의 "이번 학기 개설과목" 안내)에 들어가는 실제 개설 분반 데이터의 출처와 갱신 방법.

## 원본 파일
| 파일 | 범위 | 확보 방법 |
|---|---|---|
| `db/curriculum/_source/전공시간표_2017-2026.json` | 컴퓨터·소프트웨어공학과·공학3계열, 2017-1 ~ 2026-2 | 2026-08-15 공개 전공시간표 조회에서 확보(시드 주석 기준) |
| `db/curriculum/_source/전공시간표_2026-2_전학과.json` | **전 학과 2026-2학기**(앱 학과 108개, 학과·전공 147개, 1,901행) | 2026-10-13 사람이 직접 조회 → PDF 저장 → 아래 도구로 정리 |

같은 학과·학기가 두 파일에 다 있으면(컴소공·공학3계열 2026-2) **전 학과 파일이 우선**한다(더 최신). 시드: `npm run seed:course-offerings --workspace=server`(재시딩 크론 목록에 있음, `db/curriculum/**` 변경이라 `main` 반영 시 `db-reseed` 승인).

## 2026-2학기 전 학과 수집 (2026-10-13)
- 화면: 웹정보서비스 **학과/부/계열별 시간표 조회**(`intra.wku.ac.kr/.../TimeTable/timeTableByDept.jsp`, 로그인 없이 공개). 이 화면은 **이번 학기만** 보여 준다(연도·학기를 바꿔 보낼 수 없음).
- 방법: 대학 → 학과(전공) → 시간표 조회 → **화면 출력(PDF로 저장)**을 사람이 직접 반복. 웹정보서비스의 `robots.txt`가 자동 접근을 거부(`Disallow: /`)하므로 프로그램으로 수집하지 않았다. 화면에서 복사가 막혀 있어 PDF로 저장했다.
- 결과: PDF 172개 → 읽기 오류 0, 중복 0, 빈 표 1(농생명·바이오계열: 학과 칸에 고를 것이 없음).
- 확인한 "없음"(누락 아님): 2026 계열의 전공 단위 일부(의생명공학계열 3개 전공, 경영계열·경제금융·회계세무계열·소방행정·방재계열 각 2개, 경찰·공공행정계열 교정보호학전공 — 2026학번은 2학년 진급 시 전공을 고르므로 아직 과목 없음), 공공정책대학·독립학과(대학)(학과 없음), 복지·보건학부·행정공공기관학과(시간표 없음), 2017~2023년에 없어진 학과들.

### 정리 규칙
- **잘린 학과 이름:** 사이트 학과 칸 폭 때문에 PDF 머리글의 긴 이름이 잘린다(예: "디자인융합계열 패션디자인산업전"). `departments.json`의 "학과 트랙" 전체 이름 중 앞부분이 하나로만 맞으면 복원한다. 계열 이름만 찍힌 두 PDF(242·243)는 학수번호 앞자리로 판단해 손으로 연결했다 — M02 → 공학1계열 건설환경공학전공(M01 건축·M03 도시), M07 → 공학2계열 철도시스템공학전공(M04 기계·M05 전기·M06 전자·M08 화학).
- **같은 학과가 두 대학 아래:** 사이트가 개편 전·후 대학 아래에 같은 학과를 모두 보여 준다(건축학과, 간호학과, 응급구조학과, 의료상담학과, 안전보건학과, 스포츠과학부, 반려동물산업학과, 군사학과, 디자인융합계열 파인아트전공). 내용이 서로 달라(옛 학번용 과목 / 새 교육과정 과목) 둘 다 넣고, **같은 학수번호·분반은 한 번만** 넣는다(시드 단계).
- **앱에 없는 과정(24개):** JST공유대학, 융합전공(스마트금융SW융합전공 등), 인문대학 신설 전공(글로벌 K-컬처 등), 농생명·바이오학과 — 원본의 `unmapped`에 남기고 시딩하지 않는다. 앱 학과 목록에 추가되면 다시 연결하면 된다.
- 구분 "학석"(6행)은 정규 구분(`category`)이 없어 원문 구분(`raw_category`)만 남는다.
- 교수 이름은 화면에 공개된 그대로 넣는다(컴소공 기존 데이터와 같은 형식).
- 컴소공·공학3계열 2026-2는 옛 파일의 `competency`(역량 태그)가 있었으나 새 파일에는 없다(이 화면에 역량 칸이 없음).

## 다음 학기에 갱신하는 법
1. 학기 중에 위 화면에서 대학·학과(전공)를 하나씩 조회해 **화면 출력 → PDF로 저장**(한 폴더에, 파일 이름 무관). 학과 칸에 고를 것이 없거나 표가 비면 건너뛴다.
2. PDF 읽기: `python -I scripts/import/parseTimetablePdfs.py <PDF 폴더> parsed.json` (pdfplumber·pypdf 필요)
3. 원본 만들기: `node scripts/import/buildTimetableSource.js parsed.json [--overrides overrides.json] --collected-at YYYY-MM-DD`
   - 출력의 "미연결" 목록을 보고, 앱 학과인데 이름이 잘려 연결되지 않은 PDF는 `overrides.json`(`{"파일명.pdf": "학과 트랙"}`)으로 연결한다.
   - 같은 조회를 두 번 저장했으면 도구가 멈추니 하나를 지운다.
4. `seedCourseOfferings.js`의 `ALL_DEPARTMENTS_SOURCE`를 새 파일로 바꾸거나 여러 학기를 읽게 늘린다. `server/test/seedCourseOfferings.datasets.test.js`가 원본 형식(학과·트랙 존재, 학년·학수번호·분반·학점)을 검사한다.
