대상: 원광대학교 통합규정관리시스템 (`http://rule.wonkwang.ac.kr/lmxsrv/main/main.srv` → `https://rule.wku.ac.kr/lmxsrv/main/main.srv`로 이동)
방법: Claude in Chrome으로 사이트 안에서 직접 요청해 본문을 읽음. 로그인 없이 공개된 자료만 사용.

## 1. 왜 "접근 불가"처럼 보였나 / 읽는 방법

- 규정 제목을 누르면 **본문이 새 창(팝업)** 에 뜨는 구조(`fullPopup`)라서, 팝업이 안 보이는 환경에서는 클릭해도 아무 일이 없는 것처럼 보였다. 본문은 화면 안의 화면(iframe) 속 주소에 있다.
- 규정 하나는 **숫자 두 개**로 식별된다: `SEQ`(규정 번호), `SEQ_HISTORY`(판본 번호). 아래 주소는 로그인 없이 GET으로 열린다(같은 사이트 안에서 요청).

| 하는 일 | 주소 |
|---|---|
| 본문 | `/lmxsrv/law/lawFullContent.srv?SEQ=<규정>&SEQ_HISTORY=<판본>` |
| 판본(날짜) 목록 | `/lmxsrv/law/lawChangeList.srv?SEQ=<규정>&SEQ_HISTORY=<아무 판본>` — `<option value=판본번호>` + 날짜 |
| 개정 이력 / 신구조문대비표 | `/lmxsrv/law/lawRevisionInfo.srv`, `/lmxsrv/law/lawOldNewList.srv` (같은 인자) |
| 전체 규정 목록(가나다) | `POST /lmxsrv/search/abcLawSerach.srv` 에 `PAGE=1&PAGE_SHOW=500&SEARCH_TEXT=가&SEARCH_TEXT_SUB=나` (글자 구간별, 총 428건) |

- 한 번에 많이 받으면 느리므로(건당 2~3초) 3개씩 동시에 받고, 백그라운드 탭에서는 타이머(`setTimeout`)를 쓰지 않는다. 출력에 `? = &`가 섞이면 도구가 차단해서 다른 글자로 바꿔 출력했다.
- 원본 파일(hwp) 내려받기(`fileDown`)는 다운로드 승인이 필요해서 쓰지 않았다. 본문 글자로 충분하다.
